# МЗСО — технический аудит, 21 ноября 2026

## Производительность
- Проверены размеры двух фотографий цеха. В локальном архиве подготовлены оптимизированные JPEG без изменения композиции.
- В исходниках используются Next.js Image для галереи и логотипа, но CSS-фон hero пока не использует автоматическую оптимизацию Next Image.
- Lighthouse/Core Web Vitals **не измерены**: запуск браузера заблокирован политикой среды.

## SEO
- Добавлены метаданные Open Graph и временный запрет индексации (`noindex, nofollow`) для версии до публикации.
- Добавлен `app/robots.ts` с `Disallow: /` для staging. Перед запуском **обязательно убрать запрет**, настроить публичный домен, canonical и sitemap.xml.
- У основных страниц уже есть отдельные заголовки; коммерческие и юридические тексты требуют подтверждения.

## Доступность
- Добавлена ссылка «Перейти к содержимому».
- Есть `aria-expanded`, `aria-controls`, Escape и `prefers-reduced-motion`.
- Требуется доработка focus trap полноэкранного меню и проверка с клавиатурой/скринридером.
- WCAG 2.2 AA не подтверждён автоматическим или ручным аудитом.

## Безопасность
- Добавлены заголовки X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy.
- Форма КП намеренно отключена. Для её запуска необходимы серверная валидация, ограничения загрузок, защита от спама, безопасное хранение и юридическое согласие.
- Аудит зависимостей `npm audit` не завершён, потому что npm registry недоступен.

## Проверка браузера
- Подготовлена статическая HTML-демонстрация страниц для локального открытия.
- Попытка открыть её в Chromium через Playwright завершилась `ERR_BLOCKED_BY_ADMINISTRATOR` даже для локального файла и localhost.
- Следовательно, **браузерная проверка и Next.js production build не пройдены**.

## Синхронизация
- В GitHub загружены исправления метаданных, robots, заголовков и ссылки пропуска навигации.
- Две фотографии по-прежнему не находятся в GitHub. Они включены в обновлённый ZIP и HTML-демонстрацию.
- Изменения, влияющие на публичную индексацию и работающую отправку форм, не включены: требуются домен, реквизиты и серверная инфраструктура.
