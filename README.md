# МЗСО

Корпоративный сайт Миасского завода специального оборудования. Next.js, React, TypeScript.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Статус

Этап 6: первый адаптивный интерфейс. Дизайн и тексты находятся на согласовании. Страница «Продукция» представляет направления без отдельных страниц категорий и изделий. Формы пока работают в демонстрационном режиме, без отправки на сервер.
