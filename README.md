# МЗСО — одностраничный сайт

Статический сайт Миасского завода специального оборудования.

## Запуск
Откройте index.html в браузере либо запустите локальный HTTP-сервер: `python3 -m http.server 8000`.

## Структура

- `index.html` — одностраничный сайт с каталогом, информацией о предприятии, производстве, гарантии и контактами.
- `styles.css` — дизайн-токены, адаптивная сетка, компоненты и переходы. Manrope с кириллицей хранится локально в `assets/fonts` вместе с лицензией.
- `script.js` — мобильное меню, подсветка текущего раздела, появление контента при прокрутке и актуальный год.
- `robots.txt` — правила индексации.

## Изображения

Иллюстрации конвейера, обработки металла и категорий продукции сгенерированы для сайта. Подписи обозначают их как иллюстрации. Файлы WebP оптимизированы для веба, для первого экрана предусмотрено отдельное мобильное кадрирование.

Для финального sitemap.xml, canonical, og:url и SEO-аудита необходим подтверждённый публичный домен. Условия гарантии требуют юридической проверки до публикации.
