# МЗСО — корпоративный сайт

Next.js 15 · React 19 · TypeScript · Inter · Industrial Dark

## Запуск
```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Страницы
- `/` — главная
- `/products` — семь направлений производства **без переходов к моделям и категориям**
- `/production` — производство
- `/manufacturing-by-drawings` — изготовление по чертежам
- `/about`, `/delivery`, `/payment`, `/warranty`, `/contacts`
- `/request-quote` — демонстрационная форма без серверной отправки

## Важное об изображениях
Исходный SVG логотип находится в `public/logo.svg`. Две реальные фотографии цеха должны быть размещены в `public/images/workshop-wide.jpg` и `public/images/workshop-rollers.jpg`. Они присутствуют в полном архиве проекта, но **ещё не синхронизированы с GitHub**; в текущей GitHub-версии изображения по этим путям отсутствуют. Это известное ограничение.

## Проверка
В `.github/workflows/validate.yml` добавлена автоматическая проверка типов и сборки при push. Локальная установка зависимостей и запуск браузерных тестов в рабочей среде не выполнены из-за отсутствия доступа к npm registry. Нельзя считать интерфейс полностью проверенным.

## Статус
Рабочая реализация дизайна, не финальный запуск. Форма КП намеренно отключена; юридические тексты и коммерческие условия требуют согласования.

## Статическая публикация на REG.RU

Сборка: `npm install && npm run typecheck && npm run lint && npm run build`. Результат: папка `out/`, её содержимое размещается в корне сайта на статическом хостинге. Для корректных ссылок требуется поддержка `index.html` внутри каталогов (например `/products/index.html`).

**До публичного запуска обязательно:**
1. Подтвердить домен и установить `NEXT_PUBLIC_SITE_URL=https://<подтверждённый-домен>` на этапе сборки. Без него sitemap содержит адрес `example.invalid` — это намеренный маркер незавершённой настройки.
2. После проверки контента убрать `noindex` из `app/layout.tsx` и заменить запрет индексации в `app/robots.ts` на разрешение и ссылку на sitemap.
3. Добавить утверждённую OG-картинку PNG/JPG (1200×630) и подтвердить адрес сайта.
4. Загрузить недостающие файлы изображений в `public/images/`: `roller-hero.webp`, `workshop-wide.jpg`, `workshop-rollers.jpg`. Сейчас ссылки на них есть, а сами файлы в репозитории не найдены.
5. Подключить серверную обработку формы КП отдельно: статический экспорт не принимает файлы и не отправляет заявки.
6. Зафиксировать и закоммитить `package-lock.json`, созданный `npm install`; после этого использовать `npm ci` для воспроизводимых установок.

Проверки: `npm run typecheck`, `npm run lint`, `npm run build`, `npm run test:ui`. Браузерные тесты запускают локальный статический сервер из `out/`. Настройки HTTP security headers из Next.js не работают на статическом хостинге — их следует задать в конфигурации веб-сервера REG.RU.
