# МЗСО — одностраничный сайт

Статический сайт Миасского завода специального оборудования.

## Запуск
Откройте index.html в браузере либо запустите локальный HTTP-сервер: `python3 -m http.server 8000`.

## Структура
- index.html — семь согласованных разделов, семантическая разметка, метаданные SEO.
- styles.css — адаптивная сетка, типографика Google Fonts (Manrope, Inter).
- script.js — мобильная навигация, закрытие по Escape, актуальный год.
- robots.txt — правила индексации.

## Важно
В главном экране используется **абстрактная CSS-схема** конвейера, а не фотография предприятия. Реальные/сгенерированные изображения продукции необходимо добавлять только с корректными подписями; не выдавать синтетические изображения за документальные.

Для финального sitemap.xml, canonical, og:url и SEO-аудита необходим подтверждённый публичный домен. Условия гарантии требуют юридической проверки до публикации.
